RINGHIERA SMART — VERSIONE INSTALLABILE

Questa cartella contiene la versione WOW della Mini App con supporto PWA/offline.

File principali:
- index.html — applicazione
- manifest.json — installazione come app
- sw.js — cache offline
- icon.svg — icona Home

IMPORTANTE: per installarla come vera PWA con funzionamento offline, i file devono essere aperti da un indirizzo HTTPS (non come file locale). Una volta installata, l'app può funzionare offline.
